網路邊界

後端預設只在 loopback 提供服務；監聽非 loopback 位址時必須設定 API token。API Key 與 OAuth Token 不會進入 Prompt 或 Browser JavaScript。

Sandbox

工具只能使用後端驗證過的 Project 或排程根目錄。

Approval

高風險工具需要權限 profile、後端政策與單次人工核准。

秘密與備份

Provider、MCP、NetPass、SSH 憑證只保存在受限設定或環境；診斷與備份會排除秘密欄位。
