設計目標

NR-Intern 是可獨立啟動的桌面 AI Agent，Browser、HTTP Client 與桌面 Console 共用同一套後端 API。

Harness 工作迴圈

模型要求工具時執行並回填結果，沒有工具呼叫時完成回覆。

Durable Run

Run、SSE 事件、訊息與工具結果可重播，斷線不會自動取消工作。

Agent 工作迴圈

  1. 寫入 session transcript，載入計畫與工作規則。
  2. 呼叫模型、執行工具、保存結果並進入下一回合。
  3. 沒有工具呼叫時寫入 assistant message，完成 Run。

遠端部署的完成確認

上傳命令返回不代表檔案已完整抵達。副作用命令只執行一次，等待與檢查必須分開。

wait_for

`wait_for` 提供受 Run context 控制的可取消等待與進度回報。

ssh_wait

`ssh_wait` 以後端 profile 重新建立 SSH session，輪詢唯讀、冪等的檢查命令；可比對 exit code、stdout 包含／完全相等與連續穩定次數。

只有 bytes、SHA-256、原子改名後檔案或服務就緒狀態等遠端證據符合預期，才可宣稱部署完成；逾時必須如實保留未確認狀態。
