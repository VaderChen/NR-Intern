服務與執行設定

Token 與工具呼叫填 0 表示不限制；時間上限為 1～1440 分鐘。新數值會套用到之後開始的工作，不影響正在執行中的工作。

通知

預設關閉。開啟後才會顯示通知圖示，並保存 Run、工具授權與版本更新摘要。

Session 設定

Workspace root 不可由 HTTP 管理介面變更。信任權限仍須後端允許 elevated tools。

選擇 Session 後可管理模型、權限與記憶 scope。
Workspace 設定

選擇 Workspace 後，直接編輯其預設模型與常駐工作規則。

基本設定

職務說明只寫一次，之後每次對話與每個排程都會自動帶入，不必重述工作規則；Project 也可以再寫自己的說明，範圍較小者優先。上限 8000 字，內容每一輪都會佔用 Context 預算。

不同前端分頁可同時選擇不同 Workspace；此處更新只影響之後未指定 override 的 Run。

目前沒有可設定的 Workspace。

實驗性功能

這裡的功能還在設計或開發中，預設關閉。開啟後行為可能改變或被移除，正式工作請先評估風險。

回憶空間實驗性

讓 Agent 跨對話存取共同記憶：在別的對話裡確認過的偏好、決策與作法，下一次不必重講。只保存偏好、決策、限制與作法，密碼與金鑰一律排除；共享範圍是專案，單次注入最多 6 條。關閉後不影響既有記憶資料。

工具設定

          

            工具與協定
            
            
            
            
工具目錄每一輪都會整份送進提示。預設只公開精簡工具集（Shell、讀檔、列目錄、搜尋、辦公文件產出與計畫控制）；需要寫入、編輯、SSH 或記憶工具時再開啟擴充工具集。檢索會再過濾一次：可選工具超過 12 個時，只有與這次需求相關的工具進入提示，內建工具與 MCP 工具都適用，其餘工具 Agent 仍可用 find_tools 找回來直接呼叫，沒有任何工具被停用；關閉檢索會讓整份目錄進入每一次請求，大型 MCP Server 可能讓單次請求膨脹到數萬 tokens。工具呼叫預設使用 Provider 的原生 tool_calls 欄位；Provider 不支援時才改用指令模式，由模型自行輸出 JSON 指令。

          

          

            對外網路
            
            
            
關閉第一項後 http_fetch 會從 Agent 可用的工具清單消失，不需要重啟後端。第二項預設允許連線到 localhost、內網與雲端 metadata 位址；若不需要存取私有服務，建議關閉。
